# Prism - downloads

Prebuilt Windows installers for **Prism**, a liquid-glass RGB lighting controller.

**Download:** see the [latest release](https://github.com/clarson2706/prism-releases/releases/latest) and run `Prism.Setup.<version>.exe` (installer) or `Prism.<version>.exe` (portable).

Prism checks this page for updates when it opens and offers to install new versions.

If Windows SmartScreen says "Windows protected your PC", choose **More info -> Run anyway** (the app is not code-signed).
